multiagent-protocol setup wizard

Generate config files for your installation. Nothing is sent anywhere — this runs entirely in your browser.

1 Owner identity

The GitHub login of the person who will approve Quadrant D PRs and push break-glass commits. The bot trusts reactions/comments only from these logins.

2 Supervised repositories

Which repos do you want the bot to gate? One per line, in owner/repo form.

3 Runner tier

Where does the bot's cron tick run? Most users start with the Free tier.

4 Built-in skills

Toggle the built-in skills. Leave defaults unless you have a specific reason to disable.

5 Agent registry

Which AI agents do you use? The bot accepts commits only from these agents' identities.

6 Download config files

When you click Generate, the wizard creates the 5 config files. Either download as a ZIP and unzip into your repo, or copy each file individually and open the pre-filled GitHub "create file" link.
