multiagent-protocol

여러 AI 코딩 에이전트를 사용하는 1인 개발자/소규모 팀을 위한 self-built branch protection. Vendor-neutral. GitHub Free tier 호환. Plugin 확장 가능.

English

무엇을 하나요

  • L1 사전 머지 게이트 — PR이 머지되기 전 5 조건
  • L2 사후 재검증 — main의 실제 회귀를 탐지해 revert 명령이 담긴 인시던트를 생성, infra-only 실패는 무시 (Actions outage)
  • L3 race-guard — 머지 직전 base 재확인
  • L4 identity gate — Agent-* commit trailer를 registry와 대조
  • L5 break-glass auditor — [break-glass-*] commit 감지 + 24시간 내 ADR 요구
  • Decision Inbox — Quadrant D (비가역+critical) PR이 구조화된 ballot이 있는 GitHub Issue로 도착

왜 "Claude"/"Codex"가 아니고 "multiagent"인가

프로토콜은 모든 에이전트를 동등하게 취급합니다. 새 vendor 추가는 config/agent_registry.yml에 한 줄입니다. Identity는 commit trailer로 강제되며 API endpoint에 의존하지 않습니다.

이게 아닌 것

  • CI/CD 시스템 아님 — 본인 test 가져와야 함
  • 코드 리뷰어 아님 — 라우팅만; diff 품질 의견 없음
  • GitHub Pro branch protection 대체 아님 (결제 가능하면 그것이 더 간단)
  • Multi-tenant SaaS 아님 — 각자 본인 copy 운영
