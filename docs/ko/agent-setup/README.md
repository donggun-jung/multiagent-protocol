# 에이전트 대행 설치 (한국어 안내)

**설치는 사람이 하지 않습니다.** multiagent-protocol의 설치 표준 경로는,
이 도구를 쓰고 싶은 사람이 **자신의 AI 에이전트에게 설치를 통째로
맡기는 것**입니다. 사람이 하는 일은 딱 두 번 — GitHub App을 등록하는
클릭 몇 번(4단계)과, "이제 진짜로 작동시켜도 좋다"는 최종 확인(8단계) —
뿐입니다.

## 하는 방법

1. [설정 위저드](https://donggun-jung.github.io/multiagent-protocol/wizard/)를
   열고 질문에 답합니다. 내 GitHub 계정, 지킬 저장소, 그리고 **내 취향**
   (에이전트가 나에게 말할 언어, 보고 스타일, 어디까지 알아서 할지)을
   입력하면 설정 파일 6개와 **에이전트에게 붙여넣을 위임 프롬프트**가
   생성됩니다. 입력한 내용은 어디로도 전송되지 않고 브라우저 안에서만
   만들어집니다.
2. 그 프롬프트를 **내 AI 에이전트**(Claude Code, Codex 등)에게
   붙여넣습니다.
3. 에이전트가 영어 런북
   [`docs/agent-setup/AGENT_SETUP.md`](../../agent-setup/AGENT_SETUP.md)의
   0–9단계를 순서대로 실행합니다. 각 단계에 검증 절차가 붙어 있어,
   실패한 채로 다음 단계로 넘어가지 않습니다.

## 왜 런북은 영어인가

런북의 독자는 사람이 아니라 **에이전트**입니다. 에이전트는 영어 지시를
가장 안정적으로 따르고, 운영자와의 대화는 설정한 취향
(`preferences.yml`의 언어 설정)에 따라 **당신의 언어**로 합니다.
사람이 읽을 안내는 이 문서와
[한국어 빠른 시작](../guide/quick-start.md)이 담당합니다.

## 설치가 끝나면

- 지정한 저장소의 `main`에는 **게이트를 통과한 변경만** 합쳐집니다.
- 되돌리기 어렵거나 중요한 변경은 자동으로 멈추고, **당신의 결재함**
  (GitHub 이슈)에서 승인을 기다립니다. 👍 한 번이면 승인입니다.
- 당신의 취향은 `config/preferences.yml`(비공개 저장소)에만 저장되며,
  공개 저장소로는 절대 나가지 않습니다.
